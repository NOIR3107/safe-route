# Deploying SafeRoute

| Part | Host | Config in this repo |
|---|---|---|
| Frontend (React) | Netlify (project `saferoute-jss`) | `frontend/netlify.toml` |
| Backend (FastAPI) | Render (Docker, free plan) | `render.yaml`, `backend/Dockerfile`, `backend/docker-start.sh` |
| Databases | Supabase project `safe-route` (Singapore) | live data in `postgres`, drills in `saferoute_drill` |

The backend cannot run on Netlify: it keeps WebSocket connections open and runs a background
operation clock, and Netlify functions stop after each request.

## 1. Supabase: get the connection strings

1. Supabase dashboard, project **safe-route**: **Project Settings → Database → Reset database password**. Save the new password somewhere safe.
2. Click **Connect** (top bar) → **Session pooler** and copy the URI. It looks like
   `postgresql://postgres.yywnvizudmhnpgkemvkm:[YOUR-PASSWORD]@aws-…-ap-southeast-1.pooler.supabase.com:5432/postgres`
3. Put your password in place of `[YOUR-PASSWORD]` and add `?sslmode=require` at the end. That is **DATABASE_URL**.
4. The same string with `/saferoute_drill` instead of `/postgres` at the end is **DRILL_DATABASE_URL**.

Use the session pooler, not the direct connection: Render's free plan has no IPv6.

## 2. Render: the backend

1. https://dashboard.render.com → **New → Blueprint** → connect GitHub and pick **NOIR3107/safe-route**.
2. Render reads `render.yaml` and asks for `DATABASE_URL` and `DRILL_DATABASE_URL`: paste the two strings from step 1.
3. **Apply**. The first start migrates both databases and seeds the Adyar flood scenario (a few minutes).
4. When it is live, open `https://<your-service>.onrender.com/health`; it should say `{"status":"ok"}`.

`SECRET_KEY` and `INGEST_TOKEN` are generated by Render. The free plan sleeps after 15 minutes
without traffic; the first request after that takes about a minute.

## 3. Netlify: the frontend

The project **saferoute-jss** already exists (https://saferoute-jss.netlify.app).

1. https://app.netlify.com/projects/saferoute-jss → **Project configuration → Build & deploy → Link repository** → GitHub → **NOIR3107/safe-route**.
2. **Base directory**: `frontend`. Build command and publish directory come from `frontend/netlify.toml`.
3. Deploy. Every push to `main` redeploys.

`frontend/netlify.toml` sets `VITE_API_BASE_URL` to `https://saferoute-api.onrender.com/api/v1`. If Render
gives the service a different address, change it there and push. The backend allows
`https://saferoute-jss.netlify.app` and its deploy previews (`CORS_ORIGIN_REGEX` in `render.yaml`).
